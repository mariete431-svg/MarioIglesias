# MarioIglesias.

## Web nueva (2026)

El código de la web está en la carpeta `app/` (React + Vite, diseño creado con Lovable).
Para publicar cambios:

```bash
cd app
npm install
npm run build
```

`npm run build` genera la web y la copia a la raíz del repositorio, que es lo que publica GitHub Pages.
